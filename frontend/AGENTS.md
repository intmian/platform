# 前端

- 请求统一走 `common/api.ts`（`request` 不抛异常、`post` 失败抛 `ApiError`），路径自动加 `/api` 前缀。本地由 Vite 代理到后端（默认 `127.0.0.1:8080`，`PLATFORM_BACKEND` 环境变量可改）并去掉 `/api`；`/share-link/*` 也代理到后端。后端接口几乎都是 JSON `POST`，读也一样；返回 `code=0` 表示成功，数据在 `data`。健康检查是 `POST /api/check`，不是 GET。少数管理接口（`/admin/services`、`/admin/log/get`、`/admin/storage/*`）不是这个格式，见 `admin/adminApi.ts`。
- 本地访问用 `localhost:5173`，Vite 可能只绑了 `::1`，`127.0.0.1:5173` 不一定能连上。
- 包管理用 npm（`package-lock.json`），CI 依次跑 typecheck、vitest、build，类型错误会挡住部署。

## 外壳（`src/shell`）

所有路径都经过外壳：没登录显示全屏锁屏（公开应用、以及地址带 `shareParam` 参数的分享链接除外，目前只有日报的 `?t=`），`/` 是桌面，其余按 `shell/apps.tsx` 的应用清单挂载。拍过板的决定：
- 形态是“启动台 + 全屏应用”，不做多窗口。应用底部正中有悬浮胶囊：回桌面按钮、最近用过的 3 个应用（点一下直接切）、“更多”打开完整的切换面板（含“添加到桌面”）。（曾经是 iPhone 那种细横条，太隐蔽，找不到回桌面和最近应用。）
- 不给胶囊留任何空白（拍过板）：页面底部、抽屉底部都不垫空，胶囊浮在内容上，挡住了就往下滚一下让它收起。往下滚收起（页面和抽屉、弹窗里的滚动都算），往上滚、回到顶部、鼠标移到屏幕底部时出现。滚到底学 Safari 工具栏：第一次到底不弹（最后一行能看全），到底后再往下推一次才出来（滚轮要停顿 200ms 后的新一下，否则触控板惯性会直接把它带出来）。曾经页面底部垫 64px、抽屉底部也垫，代价太大被否；一到底就弹会盖住最后一行且再也滚不开，也被否。贴底悬浮的元素（比如设置页的保存条）可以抬高让开胶囊，那不占空间。
- 胶囊在小表单、确认框（antd Modal，层级 1000）下面，填到一半切不走；像页面一样的抽屉（详情、目录、设置面板）用 `shell/runtime` 的 `pageDrawerProps` 放到胶囊下面，开着时也能回桌面、切应用、添加到桌面。
- 记账不显示胶囊（作者的设定，`apps.tsx` 的 `noHomeBar`）。
- 所有 antd 弹窗统一支持 ⌘/Ctrl+回车（`Shell.tsx` 的 `useModEnterForModals`，等于替你点按钮）：点最上面那个弹窗的主按钮；只有一个按钮（比如“关闭”）就点它；红色危险按钮（删除确认）不响应；弹窗加 `className="pf-enter-closes"` 时只关闭（主按钮是“重新裁剪”这类顺手功能时用）。新写弹窗时：输入框的 `onPressEnter` 按着 ⌘/Ctrl 时不要自己提交，自己处理了 ⌘回车就 `preventDefault`，否则会提交两次。抽屉不在这套规则里，需要的自己写（任务详情、娱乐详情编辑模式 = 保存）。
- 所有应用共用窗口滚动条，外壳按应用记住滚动位置，切回来时恢复。
- “最近”只在内存里，刷新网页就清空，不存本地（拍过板：刷新后不要历史）。最多记当前应用 + 另外 3 个，每个应用记最后停留的那一页。保活应用（`keepAlive`）离开后留在后台不卸载，最多 3 个，超出卸载最早的，和最近的个数对齐；管理后台不保活。界面上不区分哪个在后台。
- 最近不提供关闭：曾经加过 ×，但它删的是历史、卸的是后台页面，两件事混在一起意义不明，已去掉。
- 登录过期时锁屏盖在应用上面，应用不卸载；请求失败会节流地调 `/check` 确认是否掉线。
- 桌面：小组件（今天、账本）和图标一样可以编辑（移除、拖动排序、在“添加”里加回）；Todone 图标和 Todone 清单快捷方式挂逾期数角标。链接（站内快捷方式、外站）就用原图标（快捷方式用所属应用的插画），左下角一个小箭头表示是链接，靠下面的名字区分；改成书签条、浅底写字的方案都被否过。Dock 左边是固定的（最多 5 个），是额外钉的一份，图标在桌面格子里照样保留（拍过板：不学 iPhone 那样挪走）；右边自动显示最近用过、没放进 Dock 的应用（手机上整条最多 5 个），点了回到上次那一页。桌面图标拖进 Dock 是钉一份、Dock 里的拖出来是取下，松手时才决定（拖动途中挪栏会让 dnd-kit 来回跳、死循环）。订阅基本不用了，不做小组件和特殊逻辑，新桌面默认不放。
- 桌面美术照苹果主屏的思路：画面交给壁纸（按时段变色的柔光 + 纸纹 + 右下角插画），小组件保持干净的白玻璃卡片，只有标题带应用色；卡片染色、标题前放插画都被否过（太杂）。右下角插画在头像菜单“壁纸”里选，默认看板娘剪影（`public/desk/girl.png`，从设定稿四分之三侧面抠的），也可选窗台猫或不放，存在桌面布局 JSON 的 `wallpaper` 字段。图标和卡片是普通圆角加一圈淡淡的受光边；试过苹果的方圆角（`corner-shape`），角发方、被否了。
- 桌面入场（拍过板）：加载时只放壁纸柔光，等布局、小组件数据和插画图片都到了再一次性浮现，最多等 1.2 秒；不做小组件数据的本地缓存，也不靠骨架屏占位。
- 桌面布局整份 JSON 存在后端 `/misc/home/get|set`（后端不解析，带版本号，冲突时以服务器为准），本地另存一份秒开。清单里新加的应用自动出现在桌面末尾，用户移除的不会补回。
- manifest 故意不写 `start_url`：从哪一页添加到 iPhone 主屏，图标就打开哪一页。主屏图标取当前应用的 `touchIcon`（外壳按应用切换）。

写应用时要遵守（保活的应用在后台时 DOM 还在、router 的 location 冻结在离开时那一页）：
- 新应用：在 `apps.tsx` 加一项，入口组件里用相对路径的 `<Routes>`。登录由外壳保证，应用里不要再做登录框，用户从 `useAuth()` 取。
- 不要直接改 `document.title`、favicon，不要用 `window.history` / `popstate` / `window.location.pathname`：标题用 `shell/runtime` 的 `useAppTitle`，导航用 react-router。
- “回到前台就刷新”的逻辑要同时挂 `useAppActive`（应用之间切换不会触发 `visibilitychange`）。挂在 body 上的抽屉、全局键盘监听要看 `useIsAppActive()`，否则会盖到别的应用上或在后台响应。像页面的抽屉加 `{...pageDrawerProps}`，`open` 同时看 `useIsAppActive()`。
- 能“添加到桌面”的二级页面要把状态放进地址（比如娱乐详情的 `?library_detail=`），并在保活时响应外部改地址（已经停在这一页时从桌面点链接，组件不会重新挂载）；标题用作品名之类，桌面链接的名字就是它。
- 固定在底部的元素要让开横条：`bottom: calc(var(--homebar-h) + var(--safe-bottom) + 12px)`。
- 页面底色不是白色的应用（灰底）在 `apps.tsx` 里标 `grayPage`，由外壳给整页铺底色；应用自己不要写 `min-height: 100vh` 加背景，否则手机上拉过头会露白、页面还可能多出一截能滚。
- 手机上不要把按钮固定在屏幕顶部或贴着页面最上沿：iPhone 的 Safari 收起工具栏后，状态栏下面一条会被系统模糊掉（Todone 目录、日报日历都踩过）。浮动按钮放到下方角落、让开胶囊；页面顶部的内容至少留 22px。
- 应用里不要放网站 logo、页头或“回首页”链接，回桌面交给外壳。
- 屏幕尺寸只用 `common/breakpoints.ts`（只看宽度，不看 UA）。

## 复用和约定

- 先复用再造轮子：
  - `common/UniConfig` + `ConfigsCtr`：通用配置表单（读写走 `common/cfgApi.ts`）；
  - `common/MenuPlus`：应用内分区导航（桌面是左右对开：左边整列导航贴边、右边内容；手机是顶部标题 + 横条），每个分区是一个子路由，方便固定到桌面（管理、脚本、试验场在用）；
  - `common/PageHeader`（`PageHeader` + `PageCard`）：分区页面统一的标题行（标题、一句关键信息、右边操作按钮，手机上按钮收进“更多”）和内容卡片。管理后台每一页都用它，新页面照着用，不要各自在内容里放标题和按钮；
  - `common/aiGateway.ts`（`sendAiAction`、`transcribeAudio`）：AI 调用一律走它，后端按 action 白名单处理；
  - `common/WhisperButton` + `useAudioRecorder`：语音输入；
  - `appendNoCacheParam`（`todone/Library.tsx`）：给远程图片加 `__cf_bust`，绕开 CDN 旧缓存的 CORS 问题。
- 语音输入（实时模式）拍过板的行为：点下立即开录，连接在后台建；断线自动重连并把最后一句定稿之后的音频补发，不丢不重；30 秒没出新字（离线时看音量）自动结束，硬上限默认 5 分钟；到最后仍转不出的录音存进 IndexedDB（`common/voicePending.ts`），按钮角标手动重试，文字插到当前光标。预览直接显示在输入框里，不用气泡。
- 颜色用 antd theme token；普通 CSS 用 `shell/theme.tsx` 写到 `:root` 的 `--pf-*` 变量，不写死色值（有含义的数据色除外）。新页面在不破坏现有风格的前提下可以有自己的设计。
- 图标：应用图标是同一个角色（Platform娘）拿不同道具的二次元插画，设定稿在 `icon-src/platform-girl-handbook.html`，新应用照它生成；主图标（窗台猫）保持正式简约。母版放 `icon-src/<id>-1024.png`，导出到 `public/icons/<id>-512/-192/-64.png`（桌面按实际显示的像素自动挑，高清屏上的大图标用 512；用 192 缩会发软，别为了体积再压）、`-180.png`（iPhone 主屏，必须不透明）、`-32.png`（标签页，只画道具不画人），`apps.tsx` 按 id 自动取。每个图标画的是什么、两套图怎么对应，写在 `icon-src/README.md`，改图或加应用时同步更新（代码里看不出图片内容）。
- 404 和整站崩溃页都用 `misc/ErrorPage`，图是作者自己的猫（`assets/cat.jpg`），不要换成通用的空状态。
- antd 按钮两个汉字之间不自动加空格（全局关掉了 `autoInsertSpace`）。
- `src/debug/debug.tsx`（`/debug`，只在本地开发出现）是组件试验场：改文件里的 `TARGET`/`TARGET_PROPS` 挂一个组件单独调交互。
- Note Mini 已经迁到独立项目 `memos-mian`，这里不再有入口。`FlagNote = 2` 保留不复用；R2 上传、AI、语音这些共享能力和历史文件链接都要保留。
