# 家庭记账本

后端在 `backend/platform/money_book*.go`（数据在服务器 sqlite，很重要）。管理类接口都要 `admin`；看板允许 `admin` 或该账本 `viewerUsers` 里的用户。

拍过板的决定：
- 后端只存原始数据（账本、项目定义、对账记录）；汇总、结构、趋势、记账建议都由前端从原始记录加项目配置算出来。记录里不存汇总字段，`intervalDays` 是派生出来的，不能落库。
- 项目的 `type` 只是分组展示用的自由文本，不影响计算；计算只看各个 `includeIn*` 开关。内置类型显示中文，旧的英文值读到时转成中文并在保存时写回。
- 负债金额正负都可以录，存储和计算时统一转成负数，展示用绝对值。净资产为负时，负债率的分母取净资产绝对值，保证不显示负数。
- 投资项：收益 = 本期 − 上期 − 本金变动；本金变动非零时，这一条不算年化。
- 参与对账的项目，当前值强制等于实际值。
- 草稿记录可以删除，已确认的记录可以改但不能删。删除账本只做标记、隐藏，不物理清除。
- JSON 导入总是克隆成一个新账本，绝不覆盖已有账本（用于回归测试和复现）。Excel 导入按日期命名的 sheet（如 `26-04-06`），重复的 sheet 名会跳过。
- 对账页改日期、条目、事件会防抖自动保存；手动保存只是立即保存。
- 看板要在 390px 宽度下不横向溢出；趋势只显示最近 5 条记录，事件按新到旧每页 5 条。
