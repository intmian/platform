# Todone（含 Library 娱乐库、例行清单）

同一套层级 `目录 → 分组 → 子分组 → 任务`，分组类型决定页面：`0` 普通任务板、`1` Library、`2` 例行清单（`Main.tsx` 按类型分发）。后端都在 `backend/services/todone`，权限 `admin|todone`，请求里的 `UserID` 必须等于登录用户。路由 `/todone/:group`，`:group` 是编码后的 `addr|title|type`。

## 普通任务板

- 拖动和批量移动都走 `taskMove`；跨子分组移动后要刷新源、目标两个子分组。
- 已知控制台里 antd 的 `Select.Option` 弃用警告、mock R2 的域名解析失败，都不影响功能。

## Library（`Library*.tsx`）

数据边界：
- 一个作品 = 一个 Task，核心结构是 `Task.Note` 里的 `LibraryExtra` JSON。私人备注在 `library_notes` 表，评分详情（评语、模式、多维度）在 `library_score_details` 表。
- 每个周目有稳定的 UUID，备注和评分详情都按 `task_id + round_id`（评分再加 score id）绑定，绝不用数组下标或名字。主评分用 `mainScoreID`。
- 增删改备注、改评分详情都不改写 `Task.Note`，也不刷新作品的 `updatedAt`。`LibraryLogType.note` 只用于历史迁移，运行时不能再写。
- 列表上派生的状态、评分只存在内存里，不加后端字段。
- 评分详情只在用户明确打开、编辑、分享某个评分时按 ID 加载；列表、时间线、评分梯度、隐藏的弹窗都不能触发加载。
- 私人备注永远不进全库时间线、筛选和导出。

规则：
- "鸽了"：最新状态是 WAIT、没写原因、持续 30 天以上。写了原因就不算。
- 默认排序：DOING、WAIT、无状态、TODO、DONE、鸽了、GIVE_UP、ARCHIVED；同状态里收藏优先，再按 `updatedAt` 倒序。
- `updatedAt` 只在手动"刷新"或最新一条非备注、非时间线截止的记录变化时更新。
- 封面上传三份：原图 `pictureAddress`、2:3 详情图 `pictureAddressDetail`、480 宽预览图 `picturePreview`。列表读取顺序是预览图优先，详情和分享读取顺序是详情图优先，缺了就逐级回退；旧数据缺图时由前端后台补生成。
- 打分时的 AI 助手（`library.reviewNotesDigest`）只读当前周目的备注，只输出优点、缺点、值得记录的点，不自动填任何字段。
- 已知问题：直接打开 `/todone/:group` 偶尔会显示空列表，从左侧目录重新选一次就好。

## 例行清单（`Routine*.tsx`、`routineRule.ts`）

拍过板的产品决定：
- 只有设了规则的那一层（清单、子分组、分组、事项）才有节奏。没设规则的子项只是普通勾选框，跟随最近的上级：上级到了刷新日，它们一起清空重来。子项自己设了节奏就各走各的，不受上级刷新影响，也不计入上级的完成判断。
- 一层的勾选、计数、进度条只管跟它同一节奏的事项；全是各自节奏子项的分组只当容器，不显示勾选框。
- 不提前：到了刷新日才开始，没到就是"X 开始"（未开始，不能勾，不计进度）。
- 刷新当天没做完，第二天起算逾期；可以设"宽限 N 天"。到下一个刷新日还没做完，照样清空，标"前 N 期没做"。
- 刷新方式：手动、每 N 天、每 N 周的周几（可多选）、每 N 个月（月、季度、半年、年，按自然年对齐）的几号、最后一天或第几个周几，以及"完成后 N 天"（顺延）。
- 本次补充（Temp）不会自动删除，到了刷新日只清空勾选。只有"清空重来"会处理它们，弹窗里每项可以选择"留下"转为常驻。"清空重来"只清手动节奏下的勾选。
- 可选项不影响"这一期是否做完"。
- 分组和事项长得一样（没有文件夹图标）。顶层卡片额外有外框、进度条、逾期红点和"清空重来"；其他能力每一层都一样。

实现上的坑：
- 后端只存不透明的 `rule`/`mark`（`routine_nodes` 表），所有日期都由前端按本地日期算。叶子的勾选是"勾选日期 ≥ 本期开始"才算数，刷新不写库。
- 取消一个已完成的节奏层时，要用 `PrevMark` 或 `undoneMark` 恢复，不能清空成空串，否则会被当成"从没做过"而显示逾期很多天。
- 拖动：每行外面包着带裁剪的折叠容器，拖动时其他行不能平移（否则会被裁掉），被拖的行用 `DragOverlay` 浮层；落点要用指针的真实坐标，dnd-kit 的位移不含页面滚动。
- 行上的把手、展开箭头、`⋯` 都是整行高度的直角点击区，避免点偏误勾。
