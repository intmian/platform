# 订阅管理

后端在 `backend/platform/subscription*.go`，包括一个平台内置的巡检循环（不是注册的服务）。登录用户即可使用，不需要 `admin`。

- 对外下载走匿名的 `GET /share-link/:username/:token`。每次下载都实时请求上游（或 Worker 转发），只有 2xx 且能解析出流量和到期信息才算可用；开启缓存时，可用的响应体会被存下来，上游失败或解析不出来时回退到最后一次的缓存（响应头带 `X-Subscription-Cache: HIT`）。
- 解析优先读 `subscription-userinfo` 响应头，读不到再回退解析正文里的 `Traffic:` / `Expire:`。
- 巡检解析失败时不能覆盖上一次可用的缓存。修改上游地址、Worker 地址、Worker 开关或缓存开关时，会清空已存的缓存。
- 接口返回的分享链接是相对路径，前端用当前 origin 拼成完整地址。
- 卡片：桌面端按断点 4/3/2/1 列，保证单卡不小于 360px；三个指标块（本期用量、过期时间、上次检查）没有数据时也要显示"无数据"。
