# 图标清单

图片的内容在代码里看不出来，这里用文字记下每个图标画的是什么。改图、加应用时同步更新这张表。

## 两套图，用在不同地方

| 文件 | 内容 | 用在哪 |
|---|---|---|
| `public/icons/<id>-512/-192/-64.png` | 大图：Platform娘拿着一个道具（二次元插画，设定稿见 `platform-girl-handbook.html`），母版 `icon-src/<id>-1024.png` | 桌面、Dock、⌘K、切换面板（按显示像素挑尺寸） |
| `public/icons/<id>-180.png` | 同上，不透明 | iPhone 主屏 |
| `public/icons/<id>-32.png` | 小图：只有道具，没有人物，卡通画法（米黄色道具加深色描边，放在应用色方块上），道具跟大图里的对应 | 浏览器标签页 favicon |

人脸在 32px 下看不清，所以小图只画道具。小图没有单独的源文件，只有这些 PNG。
